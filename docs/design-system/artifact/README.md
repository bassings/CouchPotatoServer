# Design System artefact source

`project/` is the source of the published CouchPotato Design System artefact
(claude.ai Design System type): `tokens.json`, the brand-book `README.md`,
per-component guidelines and static previews, and `components/bundle.css`.

Extracted from `couchpotato/ui/templates/base.html` and the partials at
`master@3d4a096`. Where this and `../README.md` disagree, the code wins, and
so does this folder: it records primary-button text as black (`text-black`),
light-theme status text as the 700 shades, and a `#0e7490` light focus ring.

Logo files are uploaded to the artefact from `couchpotato/static/` and are
referenced by blob id in `project/design-system.json`; they are not copied
here. `tokens.css`, `api/` and `manifest.json` are generated by the artefact
page and are deliberately absent.
