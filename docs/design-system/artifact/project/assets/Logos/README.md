# Logos

- `couch.png`: the primary mark, full-colour raster (red couch, green download arrow), 636×636. Sidebar brand row at 28px with `radius-sm`, beside the live "CouchPotato" wordmark. Never recolour or place it on `cp-accent`.
- `icon-512.png`: PWA / home-screen icon (the same couch, cropped). Also shipped at 72–384px in `couchpotato/static/icons/`.
- `safari.svg`: single-ink pinned-tab mask. Its ink is black (no fill set); Safari tints it with the `theme-color` `#35c5f4`. It cannot inherit colour through `<img>`, so show it only on a light ground.
